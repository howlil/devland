# Code of Conduct

Devland is maintained as an open technical project. Participation should remain professional, useful, and focused on the work.

## Expected behavior

Contributors and maintainers are expected to:

- discuss ideas and code on their technical merits;
- give specific, actionable feedback rather than personal criticism;
- assume good faith while still challenging incorrect claims or unsafe designs;
- respect different levels of experience and communication styles;
- keep security reports and other sensitive information in appropriate private channels;
- avoid harassment, discrimination, threats, doxxing, spam, and deliberately disruptive behavior.

## Scope

This code applies to project-managed spaces such as issues, pull requests, reviews, discussions, and other collaboration channels used for Devland.

## Enforcement

Project maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the project or its contributors.

For conduct concerns that should not be handled publicly, contact the maintainer through an appropriate private GitHub channel. Security vulnerabilities must use the process in [`SECURITY.md`](SECURITY.md).
