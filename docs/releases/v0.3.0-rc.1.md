# Devland v0.3.0-rc.1

This release candidate closes the M1–M7 stabilization sequence and prepares the next supported GitHub Release without changing behavioral contract `1`.

## Highlights

- transient work continuity from intent and acceptance criteria into resolved context;
- criticality-driven TDD and risk-routed verification instead of mandatory test-layer ceremony;
- explicit verification-selection semantics and advisory mismatch diagnostics;
- deterministic work → change → merge → production correlation with evidence coverage;
- production → outcome correlation, observation latency, and explicit unknown outcome coverage;
- read-only MCP feedback surface with exactly `resolve_context`, `doctor`, and `flow_report`;
- external Wago dogfood demonstrating rapid/guided/deliberate context resolution and honest empty-evidence behavior;
- release verification now exercises packaged `doctor` and `flow` commands and version-tagged MCP images.

## Compatibility

- package: `0.3.0-rc.1`;
- behavioral contract: `1`;
- canonical project/state schemas remain compatible with the current contract;
- npm publication remains disabled; GitHub Releases are the supported downloadable distribution channel during pre-1.0 stabilization.

## Product boundary

Devland remains a small SWE semantic control plane. It is not a coding agent, repository client, shell/test runner, CI/CD controller, deployment system, analytics backend, dashboard, or multi-agent orchestrator.

## Release-candidate intent

The RC exists to verify the packaged CLI and version-tagged MCP image through the real release paths before a stable `v0.3.0` decision. Stable release promotion still depends on real external delivery/outcome evidence and repository governance enforcement through an administration-capable GitHub settings surface.
